# RentFlow

RentFlow is a rental property management web app built for Kenyan landlords, property managers, and tenants. It brings rent collection, M-PESA payment verification, maintenance tracking, tenant management, and property insights into one place.

## Features

- Manage properties, units, tenants, and managers
- Track rent payments and outstanding balances
- Verify M-PESA payment submissions
- Receive and resolve maintenance requests
- View revenue, occupancy, and payment reports
- Role-based dashboards for landlords, managers, and tenants

## Tech stack

- React 19
- Vite
- React Router
- Tailwind CSS
- Lucide React icons

## Getting started

```bash
cd client
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Available scripts

Run these commands from the `client` directory:

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run lint     # Run ESLint
npm run preview  # Preview the production build
```
